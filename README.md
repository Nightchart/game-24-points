# 24 点 · 加减乘除

一个纯粹的数学小游戏：四张牌（1~13），用加、减、乘、除算出 24，每张牌只能用一次。

## 玩法

- **单人模式**：每题限时 60 秒，超时自动公布答案进入下一题；支持撤销、重来、看答案，战绩统计（正确率 / 连击 / 最快一题）
- **好友对战（同题竞速）**：创建房间，把对战链接发给好友；两人做同一批题目实时比拼，共 5 题，解出多者胜，平局比总用时
- 支持键盘：数字键选牌，`+ − * /` 选运算符，退格撤销

## 特性

- 单文件实现，零依赖、零后端：对战基于公共 MQTT over WebSocket 中转，双方各自连出，无需注册
- 出题内置穷举求解器，保证每题必有解；中间结果按分数精确运算，不受浮点误差影响
- 同种子确定性出题，对战双方题目完全一致

打开 `index.html` 即玩。
